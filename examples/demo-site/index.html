About hodo

hodo is a small browser engine written in Rust, built one stage at a time.

It aims to be simple, fast, and easy to understand.

The outer box has a solid blue border and a light blue background.

The nested box has a dashed red border and a pale red background. Nesting boxes is how the page is built up from simple pieces.

This paragraph is deliberately long so that the layout engine has to wrap it across several lines inside the 1200 by 800 pixel viewport. It keeps going with more words, testing that text measurement, line breaking, and vertical stacking all work together. When the line reaches the right edge of the content area, the next word should move down to a fresh line, and the following paragraphs and list should continue below without overlapping anything. A browser that can do this correctly is well on its way to rendering real documents.

  • HTML parsing into an arena DOM
  • CSS parsing, selector matching, and style resolution
  • Block-flow layout into a flat display list
  • Software rasterization into an RGBA frame buffer
